FOLDER STRUCTURE
================
sniah/           - S-NIAH (Single Needle-in-a-Haystack), from RULER benchmark
browsecomp_plus/ - BrowseComp-Plus (1K docs), multi-hop QA over 6-11M token corpus
oolong/          - OOLONG trec_coarse split, linear complexity aggregation
oolong_pairs/    - OOLONG-Pairs (our novel variant), quadratic pair aggregation
longbench_codeqa/ - LongBench-v2 CodeQA, code repo multi-choice QA
